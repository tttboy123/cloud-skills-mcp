The universal adapter signs current general OpenAPI requests with ACS3, product APIs that still document legacy RPC or ROA V2 with HMAC-SHA1, MaxCompute project/data/Tunnel requests with ODPS V2 or V4, classic Function Compute requests with FC HMAC-SHA256, current `fcapp.run` triggers with their Action-less ACS3 variant, custom-domain triggers with the documented POP HMAC-SHA1 request, OSS data-plane requests with V1 or V4 Header authentication, SLS data-plane requests with v1 or v4, MNS requests with its service-specific HMAC-SHA1 protocol, RocketMQ 4.x publish/consume/settlement with its distinct `MQ` HMAC-SHA1 XML protocol, ACR Enterprise Registry calls with an internal RPC-derived temporary login plus exact Bearer challenge, and Tablestore protobuf data-plane requests with OTS v2 or v4. RocketMQ receipt/transaction handles and all ACR Registry credentials remain internal. For NLS, it signs the fixed `CreateToken` RPC internally, caches the bounded temporary token until its documented expiry, and uses it only in a validated HTTPS request header or WSS handshake. It never exposes credential-minting operations as public MCP calls and never executes Alibaba Cloud CLI, Docker, or a credential helper.
